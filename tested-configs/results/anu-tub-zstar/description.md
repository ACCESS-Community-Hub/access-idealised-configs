!!! abstract "Description (as on the Overview)"
    "A bathtub-sector ocean configuration for MOM6 ... designed primarily as a test case for implementing new vertical coordinate systems into MOM6" ([README](https://github.com/ACCESS-Community-Hub/anu-tub#anu-tub)). By Andy Hogg and Angus Gibson.

    Tested set-up, read from this run's `MOM_parameter_doc.all`:

    - **Grid:** 160 x 800 points, 75 layers/levels (`GRID_CONFIG = mercator`)
    - **Vertical coordinate:** `ZSTAR`
    - **Topography:** `TOPO_CONFIG = file`
    - **Surface forcing:** `WIND_CONFIG = file`, `BUOY_CONFIG = file`
    - **Run length:** 31 days
